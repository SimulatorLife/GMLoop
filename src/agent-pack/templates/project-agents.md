# Auto-Game Project Guidance

This GameMaker project uses project-scoped Agent Skills from `.agents/skills/`.

- Read the applicable skills before planning or changing the game.
- Treat the active `.yyp` file's directory as the project root.
- Inspect existing resources and conventions before creating or changing them.
- Prefer structured project tooling when it is available instead of editing GameMaker metadata as unstructured text.
- Keep changes bounded, verify the narrowest relevant behavior, and report evidence from validation, builds, and runtime checks accurately.
- Follow the active AI tool's existing permission, trust, and execution model. This project guidance adds no separate permission layer.

Project-authored instructions in this file take precedence over generic guidance from the installed agent pack.
